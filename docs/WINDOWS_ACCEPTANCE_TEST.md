**الإصدار المرجعي:** commit `3a16d65e` — يوليو 2026  
**البيئة المستهدفة:** Windows 10/11 — تطبيق Electron  
**شرط الاعتماد:** نجاح جميع البنود العشرة

## القواعد المعتمدة (مرجع للمطوّر)

| الإعداد | التنفيذ | ملاحظة |
|--------|---------|--------|
| `opening_transition` | CSS animation في `TransitionOverlay` | يعمل في Web + Electron |
| `view_mode` | class على `<html>`: `view-compact` / `view-wide` | يعمل في Web + Electron |
| `fullscreen_on_start` | `win.maximize()` عند `ready-to-show` | **Maximized** وليس Fullscreen — مناسب لـ ERP |
| `remember_window_size` | `window-state.json` في AppData | مُعطَّل إذا كان `fullscreen_on_start = true` |
| `remember_last_opened_tabs` | `localStorage.onesoft_open_tabs` | يُستعاد **فقط** إذا `startup_page = last_opened` |
| `startup_page` | `getStartupPath()` في `LoginPage.tsx` | يتجاهل التبويبات المحفوظة إلا في حالة `last_opened` |

**أولوية التعارض:**
```
fullscreen_on_start = true  →  يتجاهل remember_window_size (canRestoreSize = false)
startup_page ≠ last_opened  →  يتجاهل remember_last_opened_tabs
```

## قائمة الاختبار

### A — انتقال تسجيل الدخول (opening_transition)

| # | الخطوة | المتوقع | النتيجة |
|---|--------|---------|---------|
| 1 | اختر `split_center` من إعدادات الهوية، ثم سجّل دخولاً **صحيحاً** | تظهر حركة الانقسام من المركز عند الدخول | ☐ |
| 2 | اختر `none`، ثم سجّل دخولاً صحيحاً | يدخل مباشرةً بدون أي حركة | ☐ |
| 3 | أي انتقال محدد، ثم أدخل **كلمة مرور خاطئة** | لا تظهر أي حركة (الانتقال يُشغَّل فقط عند نجاح الدخول) | ☐ |

### B — وضع العرض (view_mode)

| # | الخطوة | المتوقع | النتيجة |
|---|--------|---------|---------|
| 4 | اختر `compact` | صفوف الجداول أكثف (ارتفاع ~21px)، حجم الخط 11-12px | ☐ |
| 5 | اختر `wide` | صفوف الجداول أرحب (ارتفاع ~30px)، حجم الخط 13-14px | ☐ |

### C — حجم النافذة (Electron فقط)

| # | الخطوة | المتوقع | النتيجة |
|---|--------|---------|---------|
| 6 | فعّل "فتح البرنامج مكبّرًا" → أغلق البرنامج → أعد التشغيل | تفتح النافذة مكبّرةً تلقائياً | ☐ |
| 7 | عطِّل الخيار السابق، فعّل "تذكر حجم النافذة" → غيّر حجم النافذة وموضعها → أغلق وأعد التشغيل | يرجع نفس الحجم ونفس الموضع | ☐ |
| 7b | فعّل كلا الخيارين معاً → غيّر الحجم → أغلق وأعد التشغيل | يفتح **مكبّراً** (فتح مكبّر له الأولوية، يتجاهل الحجم المحفوظ) | ☐ |

## ملاحظات للمختبِر

- جميع الإعدادات (A–D) تُحفظ في جدول `theme_settings` عمود `config` (JSONB) على قاعدة البيانات — لا تعتمد على ملفات محلية.
- `window-state.json` يُحفظ في: `%APPDATA%\OneSoft ERP\window-state.json` (Windows).
- بنود C وD تتطلب تطبيق Electron — لا تختبر في المتصفح.
- بند 7b (تعارض الإعدادات) مهم للتحقق من الأولوية.
