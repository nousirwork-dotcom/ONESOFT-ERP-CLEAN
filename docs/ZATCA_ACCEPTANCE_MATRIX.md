## اختبارات مرحلة نموذج الربط الحالية

الاختبارات الآلية الحالية في:

```text
server-app/src/tests/zatca-context.test.ts
```

وتغطي:

1. وحدة واحدة ومخزن واحد وEGS واحد.
2. وحدتان `EGS-01` و`EGS-02` بمخزنين مختلفين.
3. استخدام EGS نفسه لدفاتر:
   - `sales_invoice`
   - `sales_return`
   - `credit_note`
   - `debit_note`
4. صلاحية المسؤول.
5. رفض المستخدم غير المصرح.
6. رفض الدفتر غير المرتبط.
7. رفض أكثر من ربط فعال.
8. رفض وحدة بلا EGS.
9. رفض اختلاف البيئة.
10. رفض Production عند غياب Production CSID.
11. رفض الشهادة المنتهية.
12. رفض اختلاف المؤسسة.
13. رفض اختلاف المخزن.
14. رفض الشهادة غير الفعالة، مع إثبات عدم تسريب `privateKey` أو `secretKey`.
