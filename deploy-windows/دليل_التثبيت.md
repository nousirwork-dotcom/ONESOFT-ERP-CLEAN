# دليل تثبيت OneSoft ERP

## المتطلبات

| المتطلب | الحد الأدنى | ملاحظات |
|---------|------------|---------|
| نظام التشغيل | Windows 10 / 11 (64-bit) | |
| Node.js | الإصدار 18 أو أحدث | [nodejs.org](https://nodejs.org) |
| PostgreSQL | الإصدار 14 أو أحدث | للشركات المتوسطة والكبيرة |
| الذاكرة RAM | 4 GB | يُوصى بـ 8 GB |
| مساحة القرص | 2 GB | للبرنامج + قاعدة البيانات |

---

## طريقة 1: تثبيت بسيط (بدون Electron)

### الخطوة 1: تحضير قاعدة البيانات
1. ثبّت PostgreSQL من [postgresql.org](https://www.postgresql.org/download/windows/)
2. أنشئ قاعدة بيانات جديدة:
   ```sql
   CREATE DATABASE onesoft_erp;
   CREATE USER onesoft WITH PASSWORD 'كلمة_المرور';
   GRANT ALL PRIVILEGES ON DATABASE onesoft_erp TO onesoft;
   ```

### الخطوة 2: تثبيت البرنامج
```
1. افتح مجلد البرنامج
2. شغّل: deploy-windows\تثبيت_أول_مرة.bat
3. انتظر حتى ينتهي التثبيت
```

### الخطوة 3: إعداد الإعدادات
افتح الملف: `%APPDATA%\OneSoftERP\config.json`

```json
{
  "port": 3000,
  "dbUrl": "postgresql://onesoft:كلمة_المرور@localhost:5432/onesoft_erp",
  "jwtSecret": "ضع_مفتاح_سري_طويل_هنا",
  "backupDir": "C:\\OneSoftERP\\backups",
  "logDir": "C:\\OneSoftERP\\logs",
  "nodeEnv": "production"
}
```

### الخطوة 4: تشغيل البرنامج
```
شغّل: deploy-windows\تشغيل_البرنامج.bat
```

## طريقة 2: Setup.exe (مثبّت Windows)

### متطلبات إضافية
- **على جهاز المطوّر** (للبناء فقط):
  - Node.js 18+
  - pnpm
  - اتصال بالإنترنت لتحميل electron-builder

### خطوات بناء المثبّت
```bat
deploy-windows\build-installer.bat
```

ستجد الملف الناتج في: `dist-installer\OneSoft ERP Setup 1.0.0.exe`

### تثبيت على جهاز العميل
1. شغّل `OneSoft ERP Setup 1.0.0.exe`
2. اختر مجلد التثبيت (الافتراضي: `C:\Program Files\OneSoft ERP`)
3. سينشأ اختصار على سطح المكتب تلقائياً
4. عند أول تشغيل: يظهر مربع إعداد قاعدة البيانات

---

## ملف الإعدادات (config.json)

| المفتاح | القيمة الافتراضية | الوصف |
|---------|-----------------|-------|
| `port` | `3000` | رقم المنفذ |
| `dbType` | `postgresql` | نوع قاعدة البيانات |
| `dbUrl` | — | رابط الاتصال بقاعدة البيانات |
| `jwtSecret` | — | مفتاح تشفير الجلسات (يجب تغييره) |
| `backupDir` | `%APPDATA%\OneSoftERP\backups` | مجلد النسخ الاحتياطية |
| `logDir` | `%APPDATA%\OneSoftERP\logs` | مجلد السجلات |
| `openBrowserOnStart` | `true` | فتح المتصفح عند التشغيل |
| `zatca.environment` | `sandbox` | بيئة هيئة الزكاة |

## النسخ الاحتياطي والاستعادة

### من داخل البرنامج
1. افتح **الإعدادات** ← **النسخ الاحتياطي**
2. اضغط **"نسخ الآن"** لإنشاء نسخة
3. لاستعادة نسخة: اضغط **"استعادة"** بجانب النسخة المطلوبة

### يدوياً (pg_dump)
```bat
pg_dump -U postgres onesoft_erp > backup_2026.sql
psql  -U postgres onesoft_erp < backup_2026.sql
```

## السجلات

السجلات اليومية محفوظة في:
```
%APPDATA%\OneSoftERP\logs\
```

أنواع ملفات السجل:
- `onesoft-YYYY-MM-DD.log` — سجلات الخادم
- `electron-YYYY-MM-DD.log` — سجلات تطبيق Windows (إذا استخدمت Electron)

## إزالة البرنامج

### إزالة البرنامج (Setup.exe)
1. **لوحة التحكم** ← **البرامج والميزات** ← **OneSoft ERP** ← **إلغاء التثبيت**
2. أو: شغّل `Uninstall OneSoft ERP` من قائمة ابدأ

### إزالة البيانات يدوياً
```bat
REM حذف إعدادات البرنامج (اختياري)
rd /s /q "%APPDATA%\OneSoftERP"

REM حذف قاعدة البيانات (اختياري — تحذير: لا يمكن التراجع)
REM psql -U postgres -c "DROP DATABASE onesoft_erp;"
```

> **تنبيه**: لا تحذف `%APPDATA%\OneSoftERP` إذا أردت الاحتفاظ بالنسخ الاحتياطية.

## اختيار قاعدة البيانات

| حجم الشركة | قاعدة البيانات | الوصف |
|-----------|--------------|-------|
| صغيرة (≤5 مستخدمين) | PostgreSQL محلي | تثبيت على نفس الجهاز |
| متوسطة (5-50) | PostgreSQL على سيرفر | جهاز مخصص أو VPS |
| كبيرة (50+) | PostgreSQL مُدار | AWS RDS / Azure Database |

تغيير قاعدة البيانات مستقبلاً: عدّل `dbUrl` في `config.json` ثم أعد تشغيل البرنامج.
