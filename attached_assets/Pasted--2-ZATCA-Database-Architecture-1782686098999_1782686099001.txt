# طلب تطوير رقم (2)

# تصميم قاعدة بيانات وحدة التكامل مع هيئة الزكاة (ZATCA Database Architecture)

## الهدف

تصميم قاعدة بيانات احترافية ومرنة لوحدة التكامل مع هيئة الزكاة والضريبة والجمارك، بحيث تدعم جميع مراحل دورة الفاتورة الإلكترونية الحالية والمستقبلية دون الحاجة لإعادة هيكلة قاعدة البيانات.

---

# المتطلبات العامة

* عدم إنشاء أي كود خاص بالربط أو API قبل الانتهاء من تصميم قاعدة البيانات واعتمادها.
* جميع الجداول يجب أن تستخدم UUID كمفتاح أساسي إذا كان ذلك مناسبًا، أو Identity مع UUID خارجي عند الحاجة.
* جميع الجداول يجب أن تحتوي على:

  * Created At
  * Updated At
  * Created By
  * Updated By
  * Is Active
  * Is Deleted (Soft Delete)
* إنشاء جميع العلاقات (Foreign Keys) والفهارس (Indexes) اللازمة.
* منع التكرار باستخدام Unique Constraints حيث يلزم.

# مخرجات هذه المرحلة

لا يتم تنفيذ أي ربط فعلي مع هيئة الزكاة في هذه المرحلة.

المطلوب فقط:

1. تصميم قاعدة البيانات بالكامل.
2. إنشاء جميع الجداول.
3. إنشاء العلاقات.
4. إنشاء الفهارس.
5. إنشاء القيود (Constraints).
6. إنشاء نماذج البيانات (Models/Entities) المطابقة للجداول.
7. إنشاء ملفات الهجرة (Database Migrations) إن كان المشروع يستخدم ORM.

بعد اعتماد هذه المرحلة سننتقل مباشرة إلى بناء محرك ZATCA Core Engine وربطه بهذه القاعدة.
