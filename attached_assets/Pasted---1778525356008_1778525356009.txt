

========================================
🎯 أولاً: نظام الوحدات
========================================

الوضع الحالي:
يوجد 3 صفوف ثابتة للوحدات داخل كارت الصنف.

المطلوب:
إلغاء النظام الثابت بالكامل.

========================================
✅ المطلوب الجديد
========================================

1- يظهر صف وحدة واحد فقط عند فتح الشاشة.

الصف يحتوي على:

- اختيار الوحدة
- معامل التحويل
- باركود
- زر حذف

========================================
2- اختيار الوحدة
========================================

بدلاً من textbox عادي:

استخدم Select / Combobox.

يجلب الوحدات من جدول الوحدات المسجلة بالنظام.

مثال:

قطعة
كرتون
حبة
لتر
كيلو

========================================
3- إضافة وحدة جديدة بسرعة
========================================

بجوار اختيار الوحدة:

ضع زر + صغير.

عند الضغط:

- يفتح Popup إضافة وحدة جديدة.
- بعد الحفظ:
    يتم تحديث القائمة تلقائياً.
- ويتم اختيار الوحدة الجديدة مباشرة.

========================================
4- إضافة أكثر من وحدة للصنف
========================================

أسفل الوحدات:

يوجد زر:

+ إضافة وحدة أخرى

عند الضغط:
يتم إضافة Row جديد ديناميكياً.

========================================
5- حذف وحدة
========================================

كل Row يحتوي زر حذف.

لكن:
لا يمكن حذف آخر وحدة أساسية.

========================================
6- الوحدة الأساسية
========================================

أول وحدة تكون تلقائياً:

isPrimary = true

ومعامل التحويل = 1

ولا يمكن تعديله إلا إذا أضاف وحدة أخرى.

========================================
🎯 ثانياً: الفئات
========================================

الوضع الحالي:
الفئات لا تحتوي dropdown واضح.

========================================
✅ المطلوب
========================================

تحويل حقول الفئات إلى:

Select / Tree Select

ويظهر سهم dropdown واضح.

========================================
المطلوب داخل الفئات:
========================================

- دعم التصنيفات الجذرية والفرعية
- سهم dropdown واضح
- اختيار سهل
- lazy loading لو البيانات كثيرة
