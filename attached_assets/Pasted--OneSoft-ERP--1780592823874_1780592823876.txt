المطلوب إنشاء وحدة "مركز الرسائل والإشعارات" داخل OneSoft ERP.

الهدف:
إرسال الفواتير والمستندات مباشرة للعملاء من داخل النظام دون الحاجة لفتح WhatsApp Web.

==================================================
1- إنشاء مركز رسائل موحد
========================

الإعدادات → التكاملات → مركز الرسائل

يدعم:

* WhatsApp Business API
* Telegram Bot
* البريد الإلكتروني Email
* SMS مستقبلاً

==================================================
2- إعدادات WhatsApp
===================

إضافة شاشة إعدادات تحتوي على:

* API URL
* Access Token
* Phone Number ID
* اسم المرسل
* حالة الاتصال

مع زر:
اختبار الاتصال

==================================================
3- الإرسال من المستندات
=======================

إضافة زر:

إرسال للعميل

داخل:

* فاتورة المبيعات
* عرض السعر
* أمر البيع
* كشف الحساب
* إشعار دائن
* إشعار مدين

==================================================
4- أنواع الإرسال
================

إرسال:

* PDF
* صورة الفاتورة
* رابط الفاتورة

==================================================
5- بيانات العميل
================

إضافة الحقول التالية ببطاقة العميل:

* رقم الجوال
* رقم واتساب
* البريد الإلكتروني
* Telegram ID

==================================================
6- سجل الإرسال
==============

حفظ جميع عمليات الإرسال:

* رقم المستند
* العميل
* المستخدم
* التاريخ
* الوقت
* الوسيلة
* حالة الإرسال

(تم الإرسال / فشل الإرسال)

==================================================
7- الرسائل الجاهزة
==================

إعداد قوالب رسائل قابلة للتعديل.

مثال:

عزيزي العميل {CustomerName}

مرفق لكم فاتورة المبيعات رقم {InvoiceNo}

إجمالي الفاتورة: {Amount}

شكراً لتعاملكم معنا.

==================================================
8- الصلاحيات
============

إضافة صلاحيات مستقلة:

* إرسال واتساب
* إرسال تيليجرام
* إرسال بريد إلكتروني
* عرض سجل الإرسال

==================================================
9- المرحلة الأولى
=================

تنفيذ البنية كاملة وتجهيز النظام للعمل مع:

* WhatsApp Business API
* Telegram
* Email

بحيث يكون الإرسال مباشرة من النظام دون فتح WhatsApp Web.
