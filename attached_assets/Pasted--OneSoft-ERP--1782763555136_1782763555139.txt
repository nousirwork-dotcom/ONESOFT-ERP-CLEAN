# طلب توثيق البنية التقنية لمشروع OneSoft ERP

قبل الاستمرار في التطوير، أحتاج إلى توثيق فني كامل للبنية الحالية للمشروع حتى تكون مرجعًا دائمًا للفريق، ويسهل تطوير النظام مستقبلاً.

## أولاً: معلومات عامة عن المشروع

* اسم المشروع.
* إصدار المشروع الحالي.
* تاريخ البناء (Build Date).
* Build Number.
* الإصدار (Version).
* بيئة التشغيل الحالية.

---

## ثانياً: التقنيات المستخدمة (Tech Stack)

أوضح جميع التقنيات المستخدمة مع الإصدارات، مثل:

### Frontend

* React (الإصدار)
* TypeScript
* Vite أو Next.js
* UI Framework
* CSS Framework
* State Management
* Routing
* Form Library

### Backend

* Node.js (الإصدار)
* Framework (Express أو Fastify أو غيره)
* TypeScript
* ORM (إن وجد)
* Validation Library
* Authentication
* Logging Library

### Database

* نوع قاعدة البيانات
* ORM المستخدم
* عدد الجداول
* أسلوب الـ Migrations

---

## ثالثاً: هيكل المشروع (Project Structure)

أوضح هيكل المجلدات بالكامل مع شرح وظيفة كل مجلد.

مثال:

* client-app
* server-app
* electron
* deploy-windows
* shared
* scripts
* docs

---

## رابعاً: Architecture

أريد معرفة نمط البنية المستخدم.

مثل:

* Layered Architecture
* Clean Architecture
* Modular Architecture
* Feature Based
* MVC
* Repository Pattern
* Service Pattern

مع رسم مبسط يوضح العلاقة بين الطبقات.

---

## خامساً: Modules

أذكر جميع الوحدات الموجودة حالياً داخل النظام.

مثل:

* المبيعات
* المشتريات
* المخزون
* الحسابات
* العملاء
* الموردون
* إدارة المستخدمين
* الصلاحيات
* مركز هيئة الزكاة
* التقارير
* الإعدادات

مع بيان حالة كل وحدة (مكتملة / قيد التطوير).

## سادساً: قاعدة البيانات

* عدد الجداول.

* العلاقات الرئيسية.
* ER Diagram إن أمكن.

## الهدف

إنشاء وثيقة تقنية شاملة تكون المرجع الرسمي لمشروع OneSoft ERP، حتى يسهل تطويره وصيانته، وحتى يتمكن أي مطور جديد من فهم بنية النظام بسرعة دون الاعتماد على المعرفة الشفهية.
