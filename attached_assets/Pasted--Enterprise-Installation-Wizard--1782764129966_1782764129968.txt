# طلب تطوير: معالج تثبيت احترافي (Enterprise Installation Wizard)

## الهدف

أريد أن تكون تجربة تثبيت OneSoft ERP بمستوى البرامج التجارية الكبرى مثل Microsoft Office وSQL Server، بحيث يستطيع أي مستخدم تثبيت البرنامج وتشغيله دون أي خبرة تقنية.

---

# أولاً: معالج تثبيت احترافي

يكون التثبيت خطوة بخطوة:

* مرحباً بك في OneSoft ERP
* اتفاقية الاستخدام
* اختيار مكان التثبيت
* فحص متطلبات النظام
* تثبيت المتطلبات الناقصة
* تثبيت البرنامج
* الإعداد الأول
* إنهاء التثبيت

مع أزرار:

* السابق
* التالي
* إلغاء

وشريط يوضح نسبة التقدم.

---

# ثانياً: فحص النظام تلقائياً

قبل بدء التثبيت يتم فحص:

✅ إصدار Windows

✅ 64-bit

✅ مساحة القرص

✅ الذاكرة RAM

✅ صلاحيات المستخدم

✅ المنافذ المطلوبة

✅ Node.js

✅ PostgreSQL

✅ Visual C++ Runtime (إذا كان مطلوباً)

ويعرض نتيجة كل فحص بالألوان.

---

# ثالثاً: تثبيت المتطلبات تلقائياً

إذا لم تكن بعض المتطلبات موجودة، يقوم المثبت بتثبيتها أو توجيه المستخدم بطريقة واضحة.

الهدف أن ينتهي المستخدم ولديه بيئة جاهزة لتشغيل البرنامج.

---

# رابعاً: إنشاء قاعدة البيانات تلقائياً

بعد التأكد من توفر PostgreSQL:

* إنشاء قاعدة البيانات.
* تشغيل جميع Migrations.
* إنشاء الجداول.
* إدخال البيانات الأساسية.
* التحقق من نجاح العملية.

دون تدخل من المستخدم.

---

# خامساً: معالج الإعداد الأول (First Run Wizard)

عند أول تشغيل فقط، يظهر معالج يطلب:

* اسم الشركة.
* الرقم الضريبي.
* الدولة.
* العملة.
* السنة المالية.
* اللغة.
* إنشاء المستخدم الرئيسي.
* كلمة المرور.
* إعداد النسخ الاحتياطي.
* سؤال: هل تريد إعداد الربط مع هيئة الزكاة الآن أم لاحقاً؟

ولا يتم إجبار المستخدم على إعداد هيئة الزكاة أثناء التثبيت.

---

# سادساً: حماية الإعدادات

لا يتم حفظ البيانات الحساسة في ملف نصي غير مشفر.

المطلوب:

* تشفير كلمات المرور.
* تشفير JWT Secret.
* تشفير بيانات الاتصال بقاعدة البيانات.
* تشفير مفاتيح API.
* تشفير مفاتيح هيئة الزكاة.

مع إمكانية تغيير هذه الإعدادات من داخل البرنامج بطريقة آمنة.

---

# سابعاً: شاشة معلومات النظام

داخل البرنامج، إضافة شاشة تعرض:

* إصدار البرنامج.
* رقم الإصدار (Build Number).
* إصدار قاعدة البيانات.
* إصدار Node.js.
* إصدار Electron.
* إصدار PostgreSQL.
* تاريخ البناء.
* بيئة التشغيل.
* حالة الترخيص.
* حالة النسخ الاحتياطي.
* حالة خدمة البرنامج.

---

# ثامناً: جودة تجربة المستخدم

أريد أن يشعر المستخدم أن البرنامج منتج تجاري احترافي.

لذلك يجب أن:

* تكون جميع الرسائل واضحة باللغة العربية.
* تعرض رسائل نجاح أو خطأ مفهومة.
* تعرض شريط تقدم أثناء التثبيت.
* لا يضطر المستخدم إلى تشغيل أوامر يدوية.
* لا يضطر إلى تعديل أي ملفات إعدادات بعد التثبيت.

---

# الهدف النهائي

أريد أن يستطيع أي عميل استلام ملف التثبيت (Setup.exe)، وتشغيله، والضغط على "التالي" حتى النهاية، ثم يبدأ استخدام OneSoft ERP مباشرة دون الحاجة إلى أي معرفة تقنية أو تدخل من فريق الدعم.
