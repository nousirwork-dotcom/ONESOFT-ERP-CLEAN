مطلوب تطوير شاشة القيود اليومية بعد الحفظ لتصبح احترافية وسريعة مثل الأنظمة المحاسبية الكبيرة.

المطلوب إضافة شريط أوامر أعلى شاشة القيد يحتوي على:

[ جديد ]
[ حفظ ]
[ نسخة مماثلة ]
[ عكس القيد ]
[ طباعة ]
[ PDF ]
[ حذف ]
[ أول ]
[ السابق ]
[ التالي ]
[ الأخير ]

--------------------------------------------------

1- نسخة مماثلة من القيد
(Copy Voucher / Duplicate Entry)

المطلوب:
عند الضغط على:
نسخة مماثلة

يقوم النظام بعمل نسخة كاملة من القيد الحالي تشمل:
- الحسابات
- المدين
- الدائن
- البيان
- مركز التكلفة
- العملة

مع إنشاء رقم قيد جديد تلقائياً.

ولا يتم نسخ:
- رقم القيد القديم
- تاريخ الترحيل (اختياري)

ويتم فتح القيد الجديد مباشرة في وضع التعديل.

--------------------------------------------------

2- عكس القيد
(Reverse Entry)

المطلوب:
عند الضغط على:
عكس القيد

يقوم النظام بإنشاء قيد عكسي تلقائي:

المدين يصبح دائن
الدائن يصبح مدين

مع ربط القيدين ببعض:
- رقم القيد الأصلي
- رقم القيد العكسي

ويظهر داخل القيد:
"هذا القيد تم عكسه بالقيد رقم XXX"

ويمنع عمل عكس مرتين لنفس القيد.

--------------------------------------------------

3- الطباعة والتصدير

إضافة:
- طباعة مباشرة
- تصدير PDF
- معاينة قبل الطباعة

ويظهر في التقرير:
- رقم القيد
- التاريخ
- المستخدم
- الحسابات
- البيان
- الإجماليات

--------------------------------------------------

4- التنقل بين القيود

إضافة أزرار:

[ أول ]
[ السابق ]
[ التالي ]
[ الأخير ]

للتنقل السريع بين القيود بدون الرجوع لشاشة البحث.

ويتم تحميل القيد مباشرة بدون Reload كامل للصفحة.

--------------------------------------------------

5- تحسينات احترافية مقترحة

أ) حالة القيد
إضافة Badge أعلى الشاشة:

- غير مرحل
- مرحل
- ملغي
- معكوس

--------------------------------------------------

ب) سجل التعديلات
(Audit Log)

عرض:
- من أنشأ القيد
- آخر تعديل
- وقت الحفظ
- من قام بالترحيل

--------------------------------------------------

ج) اختصارات كيبورد

Ctrl + S → حفظ
Ctrl + D → نسخة مماثلة
Ctrl + P → طباعة
Ctrl + R → عكس القيد
F2 → بحث قيود
F3 → قيد جديد

--------------------------------------------------

د) التحقق التلقائي

قبل الحفظ:
- التأكد أن المدين = الدائن
- منع الحسابات الرئيسية
- منع القيم السالبة
- التحقق من مركز التكلفة الإجباري

--------------------------------------------------

هـ) الحفظ التلقائي المؤقت
(Auto Draft)

في حالة انقطاع الكهرباء أو المتصفح:
يتم استرجاع القيد غير المحفوظ تلقائياً.

--------------------------------------------------

و) إضافة مرفقات

إمكانية إرفاق:
- فاتورة PDF
- صورة
- ملف Excel

داخل القيد.

--------------------------------------------------

ز) البحث السريع داخل القيود

إضافة:
بحث برقم القيد
بحث بالحساب
بحث بالمبلغ
بحث بالبيان

--------------------------------------------------

ح) تلوين ذكي

- المدين بلون خفيف
- الدائن بلون مختلف
- الفرق بالأحمر عند عدم التوازن
- أخضر عند التوازن

--------------------------------------------------

ط) تحسين تجربة الإدخال

بعد إدخال المدين:
Enter
ينتقل تلقائياً للدائن ثم للسطر التالي.

--------------------------------------------------

ي) قفل القيد المرحل

إذا تم ترحيل القيد:
- يمنع التعديل
- يمنع الحذف
إلا بصلاحية مدير.

--------------------------------------------------

ك) دعم الملاحظات الداخلية

إضافة:
"ملاحظات داخلية"
لا تظهر بالطباعة.

--------------------------------------------------

ل) دعم الحفظ كقالب
(Journal Template)

مثال:
- قيد رواتب
- قيد إيجارات
- قيد مصروفات تشغيل

ويتم استدعاؤه بضغطة واحدة.
