شكل المربعات والحقول
الحقول Inputs
شكلها:


Border رفيع


Radius صغير جدًا أو بدون


ارتفاع قليل


مثال ممتاز:
.input-erp {  height: 30px;  border: 1px solid #cfcfcf;  background: #fff;  padding: 4px 8px;  border-radius: 2px;  font-size: 13px;}

شكل الـ Tabs
التبويبات عندهم:


خلفية فاتحة


Active Tab أبيض


Border سفلي بسيط


مثل:
.tab {  background: #e8e1d3;  border: 1px solid #d5d5d5;  padding: 6px 14px;  font-size: 13px;}.tab.active {  background: white;  border-bottom: 2px solid white;}

الجداول Grid Style
الـ ERP الحقيقي يعتمد على:


صفوف خفيفة


Borders رفيعة


Header ثابت


مثل:
.table-erp th {  background: #ebe7df;  border: 1px solid #d6d6d6;  font-weight: 600;}.table-erp td {  border: 1px solid #e2e2e2;}

لماذا هذا الشكل سريع؟
لأنه:


لا يستخدم Shadows كثيرة


لا يستخدم Blur


لا يستخدم Animations


لا يستخدم Gradients ثقيلة


يعتمد على CSS بسيط


وده ممتاز جدًا لبرنامج محاسبي كبير.
